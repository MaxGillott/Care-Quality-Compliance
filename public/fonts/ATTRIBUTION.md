# Local typography

IBM Plex Sans: Copyright 2018 IBM Corp. Sources: https://github.com/IBM/plex and https://github.com/google/fonts/tree/main/ofl/ibmplexsans . SIL Open Font License 1.1, included in IBM-Plex-Sans-OFL.txt. The Latin variable WOFF2 supplies headings, navigation, body text and controls.

ibm-plex-sans-og.ttf is a static weight-400 instance generated with fontTools from the same licensed font for the social-sharing image. The original copyright and name metadata are retained.

All fonts are served locally. No Apple SF Pro font files are included or redistributed. IBM's light display typography and Apple's restrained hierarchy informed the spacing and weights.
